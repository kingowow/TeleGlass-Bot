# 💎 TeleGlass Bot

A lightweight, serverless Telegram bot for creating messages with inline (glass) buttons, running on Cloudflare Workers.

این یک ربات تلگرامی سبک و بدون سرور برای ساخت پیام‌هایی با دکمه‌های شیشه‌ای است که بر روی پلتفرم Cloudflare Workers اجرا می‌شود.
